评测口径

把分数放在它该在的位置：公开题库、固定采样、可复现的判分。

智能指数

综合智能指数采用四维体系：智能体、代码、通用能力、科学推理各占 25%。缺失维度自动重分配权重，不把未测当零分。

判分方式

选择题按选项判分；数学题按最终数值并带容差；简答题归一化匹配；SWE 类按金标补丁相似度近似，官方容器判分为路线图。

模拟与真实

模拟模式用确定性画像生成分数，用于流程演示与横向对比，不产生 API 费用。真实模式需要用户显式解锁并自担 token 成本。
